=====================================================
🚀 GUÍA ACTUALIZADA PARA EL FRONTEND
=====================================================
Hola equipo! El backend está 100% estable y el CORS está abierto. Aquí tienen cómo usar las nuevas rutas:

🟢 1. REVISAR ESTADO DEL SERVIDOR
- Endpoint: `GET /health`
- Uso: Háganle ping al iniciar la app para asegurar que el backend está vivo.
- Retorna: {"status": "ok", "message": "Campus Delphos API is alive!"}

📝 2. CREAR UNA CUENTA NUEVA
- Endpoint: `POST /api/v1/register`
- Payload esperado (JSON):
  {
    "email": "nuevo.inversor@delphos.com",
    "password": "PasswordFuerte123!",
    "full_name": "Nombre Completo"
  }
- Nota: Ya no es obligatorio enviar `username`. El backend lo generará automáticamente a partir del correo.

🔑 3. INICIAR SESIÓN (OBTENER TOKEN)
- Endpoint: `POST /api/v1/token`
- Content-Type: `application/x-www-form-urlencoded`
- Form Data:
  - `username`: (¡OJO! Aquí envían el EMAIL, ej. inversor@delphos.com)
  - `password`: Su contraseña
- Retorna: `access_token` (Guárdenlo y envíenlo en el header Authorization: Bearer <token> para todo lo demás).

¡A conectar esas pantallas! 🎨
